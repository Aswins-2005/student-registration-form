# Student Registration Form

A responsive student registration form built using HTML, CSS, and JavaScript. The project collects student details, validates the form input, and dynamically adds submitted data to a table without refreshing the page.

## Features

* Responsive design for desktop, tablet, and mobile
* Student registration form
* First name and last name
* Email
* Address
* Pincode
* Gender selection
* State and country selection
* Form submission using JavaScript
* Dynamic table row creation
* Prevents page refresh on submission
* Reset/clear form functionality

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

1. Enter the student's details in the form.
2. JavaScript handles the form submission using `addEventListener`.
3. The page refresh is prevented using `preventDefault()`.
4. The entered values are collected from the form.
5. A new table row is created dynamically using JavaScript.
6. The student information is displayed in the table.
